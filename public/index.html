x402 PROTOCOL SPECIFICATION

ZERO-COST FAILURE SETTLEMENT PROTOCOL

How Meera's API strictly guarantees that callers are never charged for unparseable notices:

STEP 01

CLIENT REQUEST

Caller sends POST /parse with delay notice body.

STEP 02

402 INTERCEPT

Server gate intercepts call and returns HTTP 402 with payment-required header.

STEP 03

EIP-712 SIGN

Buyer generates EIP-712 / Permit2 signature with BUYER_PRIVATE_KEY on Base Sepolia.

STEP 04

NOTICE PARSE

Server verifies signature and runs src/parser.ts + Zod Output Schema.

STEP 05

SETTLEMENT BRANCH

VALID NOTICE (200 OK) -> x402 Settle Charge
MALFORMED (4xx) -> x402 Cancel Settlement (0 Charge!)
